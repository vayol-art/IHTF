Versión HTML + CSS limpia del diseño exportado desde Figma Make.

Archivos:
- index.html
- style.css
- assets/ imágenes originales del export

Cómo usar:
1. Sube la carpeta completa a tu hosting.
2. Mantén index.html, style.css y assets/ en la misma carpeta.
3. Cambia los enlaces # de los botones Entradas / Más información por las URLs reales.
4. Para reemplazar el banner por video, cambia en index.html la sección .hero-bg por una etiqueta <video> o actualiza el background en style.css.
